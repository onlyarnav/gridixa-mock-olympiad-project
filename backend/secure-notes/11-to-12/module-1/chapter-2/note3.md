# Function Calling (Under the Hood)

As your AI teacher, let us examine an important question about how modern AI agents interact with the real world.

A **Large Language Model** normally generates **text as its output**. It predicts words and sentences, but it cannot directly press buttons, search the internet, or access external applications.

So how can an AI agent perform real-world tasks such as searching for information or retrieving weather data?

Engineers solve this problem using a technique known as **Function Calling**, sometimes also called **Tool Calling**.

---

### The Idea Behind Function Calling

When engineers build an AI agent, they do not only provide the model with a prompt. They also provide a **structured list of tools** that the agent is allowed to use.

These tools are described in a precise programming format, usually using **JSON Schema**. This structured format acts like a **dictionary of available actions** that the AI can perform.

Each tool in this dictionary includes details such as:

* the name of the function
* the required input arguments
* the type of data the function returns

The AI model is fine-tuned to recognize situations where a tool is needed.

Instead of writing a normal English response, the model generates a **structured JSON command** that instructs the system to run a specific function.

---

### Example of Function Calling

Consider the following user request.

User prompt
“What is the weather in Paris?”

Instead of generating a sentence such as “I will check the weather,” the AI produces a structured JSON output that represents a function call.

Example internal output

```
{
  "name": "get_weather",
  "arguments": {
    "location": "Paris, France"
  }
}
```

This output is not meant for the user. It is meant for the **external software system controlling the agent**.

---

### How the System Executes the Action

Once the JSON command is generated, the external program—often written in Python—detects the structured output.

The framework temporarily pauses the language model and performs the following steps.

The system reads the JSON command generated by the model.

The program executes the corresponding function, such as calling a **weather API** to retrieve the current temperature.

The returned data is then inserted into the **context window** of the language model.

After receiving this information, the model continues generating its response and produces the final **human-readable answer**.

---

### Why Function Calling is Important

Function calling allows an AI agent to move beyond simple text generation.

By connecting the model to external tools, engineers enable the agent to perform actions such as:

* searching the web
* retrieving real-time data
* executing code
* interacting with external services

This mechanism is one of the key technologies that makes **autonomous AI agents possible**.

---

**Key Idea**

Function Calling allows a language model to interact with external systems. Instead of producing normal text, the model generates a structured **JSON command** that instructs the software framework to execute a specific tool or API. This allows the AI agent to perform real-world actions and retrieve external information.
