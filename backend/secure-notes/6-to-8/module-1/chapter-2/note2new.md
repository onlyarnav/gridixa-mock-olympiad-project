# The Early Days of Computers

In the early days of computing, computers could only follow **very strict instructions written by programmers**.

Every action had to be described with a precise rule.

### Example: A Video Game Character

Suppose a programmer wanted a game character to jump.

They would have to write instructions such as:

```
If player presses the spacebar → Move the character upward by a fixed distance
```

The computer would follow this rule exactly.

But this method had a big limitation.

If a program needed to handle **many complex situations**, the programmer would have to write **thousands or even millions of rules**.

For complicated problems like recognizing images or understanding speech, writing rules for every situation becomes almost impossible.

---

# The Idea Behind Machine Learning

Machine Learning introduced a completely new approach.

Instead of writing every rule manually, scientists give the computer:

1. **A learning algorithm**
2. **A large amount of data**

The computer then studies the data and **discovers patterns by itself**.

This process can be represented like this:

```
Large Data + Learning Algorithm → Pattern Discovery → Learned Rules
```

The important difference is that the **computer learns the rules automatically**.

---

# Traditional Programming vs Machine Learning

We can compare the two approaches.

| Traditional Programming            | Machine Learning                  |
| ---------------------------------- | --------------------------------- |
| Humans write rules                 | Computer learns rules             |
| Program follows fixed instructions | Program studies data              |
| Works well for simple tasks        | Works better for complex problems |

### Traditional Programming Process

```
Rules + Data → Computer Program → Output
```

### Machine Learning Process

```
Data + Learning Algorithm → Computer Learns Patterns → Smart Output
```

This new method allows computers to solve **much more complex problems**.

# Analogy: Learning to Ride a Bicycle

To understand Machine Learning better, think about how humans learn new skills.

Consider learning to **ride a bicycle**.

Did you learn by reading a long scientific book about:

* Balance
* Gravity
* Motion

Most likely, you did not.

Instead, you learned by **trying, observing, and improving**.

The process looked something like this:

1. You got on the bicycle.
2. You tried to balance.
3. You fell down a few times.
4. Your brain learned what works and what does not.
5. Eventually, you learned how to ride successfully.

This learning process can be represented like this:

```
Try → Observe Result → Learn Pattern → Improve Balance
```

Over time, your brain automatically discovered the **correct pattern for staying balanced**.

---

# How Machine Learning Is Similar

Machine Learning works in a similar way.

The AI system studies a large amount of data and gradually learns patterns.

For example:

If we want an AI system to recognize dogs, we may show it:

* Thousands of images of dogs
* Thousands of images of other animals

The system studies the images and learns patterns such as:

* Ear shapes
* Body structure
* Fur patterns

Eventually, it becomes able to **recognize a dog in a new image**.

The learning process can be represented like this:

```
Training Data → Pattern Learning → Model Improvement → Accurate Prediction
```

# Why Machine Learning Is Important

Machine Learning allows computers to solve problems that are **too complicated for manual programming**.

Examples include:

* Recognizing faces in photos
* Understanding spoken language
* Recommending videos or products
* Detecting objects in self-driving cars

All of these tasks involve **large amounts of data and complex patterns**.

Machine Learning helps computers **discover these patterns automatically**.

# Think Like an AI Engineer

Consider the following situation.

A scientist wants to build a system that can recognize handwritten numbers.

Which approach would work better?

A) Writing thousands of rules for every possible handwriting style
B) Showing the computer thousands of handwritten examples so it can learn patterns

**Machine Learning (ML)**

Important ideas include:

* Early computer programs relied on **strict instructions**.
* Machine Learning allows computers to **learn rules automatically**.
* AI systems improve by **studying large amounts of data**.
