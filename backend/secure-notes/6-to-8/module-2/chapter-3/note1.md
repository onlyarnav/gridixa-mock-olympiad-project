# Passive AI Systems

A **passive AI system** does not take action on its own.

Instead, it waits for a human to give it an instruction, question, or prompt.

For example:

* A translation AI waits until you give it text to translate.
* An image recognition AI waits until you upload a picture.
* A chatbot waits until you type a message.

These systems only respond when a human interacts with them.

You can think of passive AI like a **digital encyclopedia**.

You open it, search for information, read the answer, and then close it.

---

# What Is an AI Agent?

An **AI Agent** is different from a passive AI system.

An **AI Agent** is an AI program designed to **achieve a goal by interacting with its environment**.

Instead of simply answering questions, an AI Agent can:

* Observe a situation
* Make decisions
* Take actions
* Work step by step to complete a task

In simple terms, an AI Agent does not just provide information—it **gets things done**.

---

# AI Agent vs Traditional AI

The difference between a traditional AI system and an AI Agent can be understood with a simple comparison.

| Traditional AI         | AI Agent            |
| ---------------------- | ------------------- |
| Waits for user input   | Works toward a goal |
| Only answers questions | Takes actions       |
| Passive system         | Active system       |

Traditional AI responds to instructions, while an AI Agent **plans and acts** to complete a mission.

---

# Example of an AI Agent

Imagine you ask an AI system to help you organize a school event.

A traditional AI might simply give suggestions about how to organize the event.

An **AI Agent**, however, could actually help complete the task by:

1. Searching for available venues
2. Checking possible event dates
3. Creating a schedule
4. Sending reminder messages

Instead of just answering questions, the AI Agent **actively performs multiple steps** to achieve the goal.

---

# How AI Agents Work

An AI Agent usually follows a simple decision-making cycle:

1. **Observe** the environment
2. **Decide** what action to take
3. **Act** to move closer to the goal
4. **Repeat** until the goal is achieved

This continuous loop allows the agent to adapt and make better decisions as it gathers more information.

# Real-World Examples of AI Agents

Many modern technologies use AI agents to automate tasks.

Examples include:

**Virtual Assistants**

Digital assistants that schedule meetings, set reminders, and manage tasks.

**Autonomous Robots**

Robots that move through an environment while making decisions in real time.

**Smart Home Systems**

AI systems that automatically adjust lighting, temperature, or security based on user behavior.

In all these cases, the AI is **actively interacting with its environment** rather than simply responding to questions.
