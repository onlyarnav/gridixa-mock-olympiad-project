# The Core Loop — Observe → Decide → Act

Hello again.
I am **AIVA (Artificial Intelligence Virtual Assistant)**. In the previous topic, we learned that an **AI Agent** is an intelligent system designed to achieve a goal by interacting with its environment.

But how exactly does an AI Agent make decisions and take actions?

Every AI Agent operates using a simple but powerful cycle called the **Agent Loop**.

This loop allows the agent to continuously understand its environment, make decisions, and take actions.

---

# The Agent Loop

The **Agent Loop** is a three-step cycle followed by AI agents:

1. **Observe**
2. **Decide**
3. **Act**

This process repeats continuously while the agent works toward achieving its goal.

```
Observe → Decide → Act → Observe → Decide → Act
```

Each step plays an important role in helping the AI agent interact with the world.

---

# Step 1: Observe (What Is Happening?)

In the first step, the AI agent **observes its environment**.

Observation means collecting information about what is happening around it.

The agent may gather data from:

* Cameras
* Sensors
* Databases
* User inputs
* Digital systems

This information helps the agent understand the **current situation**.

### Example

A self-driving car observes:

* The road ahead
* Traffic lights
* Other vehicles
* Pedestrians

All this information helps the AI understand what is happening in the environment.

---

# Step 2: Decide (What Should I Do?)

After observing the environment, the AI agent must decide **what action to take next**.

This is where the agent uses its **AI models**, such as the Deep Learning systems we studied earlier.

The AI analyzes the collected data and calculates the **best possible action** that will help achieve its goal.

### Example

A self-driving car might decide to:

* Slow down
* Stop at a traffic light
* Turn left
* Continue driving forward

The decision is based on the information gathered in the observation step.

---

# Step 3: Act (Take Action)

Once the decision is made, the AI agent **performs the action**.

This action changes the environment in some way.

Actions can be either:

* **Physical actions**, such as a robot moving its arm
* **Digital actions**, such as sending a message or updating a schedule

### Example

A self-driving car may:

* Apply the brakes
* Turn the steering wheel
* Accelerate forward

These actions directly affect the real-world environment.

---

# The Loop Never Stops

After the agent takes an action, the environment changes.

Because the situation has changed, the AI must **observe the environment again**.

This is why the process forms a continuous loop:

```
Observe → Decide → Act → Repeat
```

The agent keeps repeating this cycle until its goal is achieved.

---

# Real-World Example: A Conference Delegate

This loop is not just used by machines—it is very similar to how humans think and act.

Consider a delegate participating in a **TYT MUN conference**.

**Observe**

The delegate looks around the room and listens to the arguments being presented.

**Decide**

They think carefully and plan a strong counter-argument.

**Act**

They raise their placard and deliver their speech.

Once the speech is given, the situation in the room changes. The delegate must then **observe the new situation**, decide what to do next, and act again.

AI agents follow **this same logical cycle**.

---

# Examples of AI Agents Using the Agent Loop

Many modern technologies use this Observe–Decide–Act cycle.

Examples include:

**Self-Driving Cars**

Observe traffic conditions, decide how to drive safely, and control the vehicle.

**Video Game Characters**

Observe the player’s actions, decide how to respond, and perform movements or attacks.

**Smart Home Systems**

Observe environmental conditions, decide the best settings, and adjust lighting or temperature.

These systems rely on the **agent loop** to operate intelligently.

# Think Like an AI Engineer

Consider the following situation.

An AI robot observes that an object is blocking its path. It calculates a new route and then moves around the obstacle.

Which part of the agent loop is the robot performing when it moves around the obstacle?

A) Observe
B) Decide
C) Act

Correct answer: **C**

When the robot physically moves to avoid the obstacle, it is performing the **Act** step.

# Key Points to Remember

**Agent Loop**

* The continuous cycle that guides AI agent behavior.

**Observe**

* The agent collects information about its environment.

**Decide**

* The agent analyzes the information and selects the best action.

**Act**

* The agent performs an action that changes the environment.

AI agents continuously repeat this cycle while working toward their goals.
