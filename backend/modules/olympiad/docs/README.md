# Gridixa AI Mock Olympiad Module

This module implements a scalable, secure, and production-ready online examination engine for the Gridixa AI platform.

---

## 1. Architectural Layout

The Olympiad is built as a self-contained module integrated inside the monorepo's backend and frontend workspaces.

```
backend/modules/olympiad/
├── config/             # Redis and connection configurations
├── constants/          # Static markers (e.g., Option labels A, B, C, D)
├── controllers/        # Thin Express routing controllers
├── models/             # Persistent MongoDB cooldown schemas
├── routes/             # Authentication endpoints mapping
├── services/           # Business logic (Scoring, Shuffling, Caching)
├── types/              # strict TypeScript mappings
└── validators/         # JSON Question bank / manifest compilers
```

### Core Design Principles
* **Separation of Concerns**: Controllers only parsing requests/responses; services execute business operations; repositories handle database connectivity.
* **Server-Authoritative Timing**: Timestamps are generated by the server and cached in Redis. System clock updates or browser refreshes on the client side do not affect the countdown.
* **In-Memory Question Bank**: Questions and set manifests are stored as static JSON files. They are parsed, validated, and cached in-memory during startup. Disk access is never executed during runtime API requests.
* **Privacy-Safe Proctoring**: Browser focus tracking and WebRTC webcam monitoring are processed entirely on the student's browser client. No screenshots, audio, or logs are uploaded or stored.

## 2. Setting Up & Testing

### Question Bank Generation
To generate mock question bank files, execute the helper script:
```bash
# From workspace root or backend/
node scripts/generate-question-bank.js
```
This generates the full questions suite inside `backend/question-bank/v1/`.

### Run Test Suite
The backend contains comprehensive unit and integration tests covering caching, validations, and scoring.
To run tests:
```bash
# From backend/
npm run test
```

### Build & Run
To run typechecks and production compilations:

#### Backend
```bash
# Run strict TypeScript compilation checks
npm run type-check

# Launch production build server
npm run dev
```

#### Frontend
```bash
# Compile optimized Next.js app pages
npm run build
```
The client dashboard sidebar maps the Mock Olympiad link directly to `/dashboard/olympiad`.
